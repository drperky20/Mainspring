# Brand

![Mainspring wordmark](../assets/brand/mainspring-wordmark.svg)

## Core Line

**Mainspring is the open-source operating system for agent businesses.**

## Product Promise

Turn raw LLM output into controlled, replayable, policy-bound, inspectable, sellable agent work.

## Why The Name Fits

A mainspring stores energy and releases it with control. That is the product idea: language models provide raw generative energy; Mainspring provides the mechanism that makes the output usable for real operator workflows.

## Positioning

Mainspring is not another chat wrapper. It is a runtime and control foundation for founders, agencies, and self-hosted operators who need consequences to live outside the model:

- tool schemas
- approvals
- receipts
- event journal
- workspace boundaries
- operator review
- replayable traces

## Taglines

- The open-source operating system for agent businesses.
- Control the work, not just the prompt.
- Replayable agent work for real operators.

## Audience

- Agency founders running managed client agents
- Product builders creating self-hosted operator tools
- Local-first developers who want control before growth
- Small teams that need traceable automation instead of black-box chats

## Differentiators

- Durable runtime spine with mailbox, kernel, policy, and event journal
- Local-first posture instead of hosted-platform lock-in
- Honest security language about current limits
- Business-oriented nouns: clients, workspaces, agents, runs, approvals, artifacts, usage
- Prototype UI that stays explicit about what is preview-only

## Voice

Clear, confident, practical, mechanical.

Prefer:

- control plane
- runtime plane
- event journal
- run trace
- approval receipt
- workspace
- operator
- agent business

Avoid:

- fake enterprise certainty
- vague AI magic language
- security theater
- bubbly SaaS filler

## Visual Direction

Use a premium mechanical editorial system:

- warm ivory surfaces
- ink-black typography
- brass accents
- oxidized green accents
- fine-line mechanical motifs
- dense but calm information layouts

The feeling should be founder cockpit, not blob SaaS, not cyberpunk toy, not sterile admin sludge.
