# Investor One-Pager

## Thesis

Agent businesses need infrastructure for consequences, not just prompts.

## Product

Mainspring supplies mailbox dispatch, runtime control, tools, policy, approvals, receipts, traces, and local-first operator surfaces.

## Why Now

The market has many wrappers and demos. Fewer teams are building replayable, inspectable, sellable runtime systems.

## Current Truth

- local-first runtime package exists
- SDK exists
- local gateway dev mode now exists
- console remains partly prototype and experimental
- secure desktop secret storage, VM isolation, billing, and hosted control plane are not implemented yet
