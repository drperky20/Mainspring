# Local Agent Security Red-Team Matrix

Last updated: 2026-07-10.

This matrix maps local-agent failure classes to current Mainspring evidence. It is deliberately conservative: a class is marked covered only when code and tests exercise the behavior.

| Failure class | Current answer | Evidence | Remaining work |
| --- | --- | --- | --- |
| Host shell execution without approval | Requires scoped approval before execution. | `src/security/agent-security-regression.test.ts`; `ToolRegistry`; `RuntimePolicyGuard`; `ShellTool` manifest. | Host execution remains unsafe host process execution after approval. |
| Loader/env-var injection through shell | Requires approval before execution. | `src/security/agent-security-regression.test.ts`. | Add deeper command risk classification before approval if advisory classifier is implemented. |
| Remote URL piped to shell | Hard-blocked below approval. | `src/security/agent-security-regression.test.ts`; `RuntimePolicyGuard` hardline patterns. | Broaden corpus as parser bypasses are discovered. |
| Interpreter indirection for remote shell install | Hard-blocked when the command carries the pipe-to-shell payload. | `src/security/agent-security-regression.test.ts`. | Add language-specific bypass samples in future corpus expansion. |
| Catastrophic filesystem wipe / fork bomb / raw disk write | Hard-blocked by policy patterns. | `RuntimePolicyGuard`; `ToolRegistry.test.ts`. | Add dedicated samples to the security corpus as follow-up. |
| Workspace `../` traversal | Rejected by path-boundary checks before file access. | `src/security/agent-security-regression.test.ts`; `PathSecurity`; `assertPathContained`. | Keep Windows and POSIX path variants in regression tests. |
| Symlink/junction workspace escape | Rejected by realpath path-boundary checks before file access. | `src/security/agent-security-regression.test.ts`; `assertPathContained`. | Add TOCTOU-aware write/open patterns where feasible. |
| Workspace mutation without approval | Requires approval and does not execute. | `src/security/agent-security-regression.test.ts`; file tool manifests. | Approved host mutations are still unsafe host filesystem changes. |
| Browser navigation to local/private target | Requires approval through browser policy path; approved initial targets are still rejected if local/private. | `src/security/agent-security-regression.test.ts`; `BrowserTool`; `RuntimePolicyGuard`. | Browser automation remains an unsafe local capability, not a browser-security boundary. |
| Web fetch SSRF to local/metadata target | Rejected before fetch. | `src/security/agent-security-regression.test.ts`; `UrlPolicy`; `WebTools`. | Keep DNS rebinding/redirect cases covered by `assertPublicNetworkTarget`. |
| Memory persistence | Requires approval, provenance scan, and staged review when content triggers review. `GatewayProvenanceReviewControl` records hash-only decision/apply authority before queue or writer mutation; hosted routes use session identity rather than a browser reviewer. Explicit operator corrections are rescanned and append a replacement journal row; deletions append a tombstone. Review apply recovers a matching durable memory write after an interrupted journal update and replays matching terminal records without a duplicate. | `src/security/agent-security-regression.test.ts`; `src/provenance/ProvenanceReview.test.ts`; `src/memory/MemoryStore.test.ts`; `src/gateway/GatewayProvenanceReviewControl.test.ts`; `src/gateway/LocalGateway.test.ts`; `src/gateway/server/createLocalGatewayServer.test.ts`; `apps/console/src/localGatewayClient.test.ts`; `e2e/console.operator.spec.ts`; `MemoryTool`. | Local operator review is not remote trust or hosted governance. |
| Skill/catalog write | Requires approval, provenance scan, and staged review for remote/uploaded or high-capability skill manifests. The same provenance control records durable pre-write authority; matching durable skill manifests recover an interrupted journal update without a second write. Signed remote templates use a separate pinned-key, text-only catalog path. | `src/security/agent-security-regression.test.ts`; `src/provenance/ProvenanceReview.test.ts`; `src/gateway/GatewayProvenanceReviewControl.test.ts`; `src/gateway/RemoteMarketplace.test.ts`; `src/gateway/server/RemoteMarketplaceServer.test.ts`; `SkillTools`; `pnpm skills:check`; `pnpm marketplace:check`. | Remote skill reputation and hosted revocation remain not implemented. |
| MCP/tool bridge bypass | Requires approval when registered through `ToolRegistry`; executor is not reached. | `src/security/agent-security-regression.test.ts`. | Future MCP host surfaces need direct DecisionRecord adapters. |
| Cron/headless side-effect escalation | Denied by default and records a cron `DecisionRecord`; RunLog-configured gateway cron schedules use the same fail-closed policy path and expose HTTP/client plus React console grant review/create. `GatewayCronControl` writes hash-only `cron.schedule.write`/`cron.grant.create` before control-plane mutation and `cron.trigger` before manual/due cursor mutation or dispatch; hosted identity overrides request-body attribution. | `src/security/agent-security-regression.test.ts`; `RunLogCron`; `SqliteRunLogStore`; `src/gateway/GatewayCronControl.test.ts`; `src/gateway/LocalGateway.test.ts`; `src/gateway/server/createLocalGatewayServer.test.ts`; `apps/console/src/localGatewayClient.test.ts`; `apps/console/src/App.test.tsx`. | Gateways without a RunLog host remain mailbox-compatible; cron grants are scoped scheduling authority, not process containment. |
| Budget control or acknowledgement spoofing | `GatewayBudgetControl` writes hash-only `budget.write` authority before configuration mutation and records `budget.warning.acknowledge` or `budget.run.block` before a warning-band or blocked run reaches an enqueue path. Hosted routes override browser attribution with the authenticated principal. | `src/gateway/GatewayBudgetControl.test.ts`; `src/gateway/LocalGateway.test.ts`; `src/gateway/server/createLocalGatewayServer.test.ts`. | Budget values are local estimated-cost controls; they cannot reserve provider spend, prevent out-of-band usage, or make provider billing guarantees. |
| Run ingress or approval-response spoofing | `GatewayRunControl` writes hash-only `run.enqueue` authority before compatibility or RunLog enqueue and `approval.resolve` authority before legacy or RunLog approval lifecycle mutation; outcome/failure rows retain only decision and binding hashes, and hosted identity overrides request-body attribution. | `src/gateway/GatewayRunControl.test.ts`; `src/gateway/LocalGateway.test.ts`; `src/gateway/server/createLocalGatewayServer.test.ts`. | Gateways without app-state remain compatibility-only and do not have a durable gateway audit store; runtime-native RunLog receipts remain the canonical approval authority. |
| Provider-profile or managed-secret authority gap | `GatewayProviderProfileControl` writes hash-only `provider_config.write` authority before provider-profile create/update can touch app-state or managed-secret encryption. Hosted routes override browser attribution with the authenticated principal. | `src/gateway/GatewayProviderProfileControl.test.ts`; `src/gateway/LocalGateway.test.ts`; `src/gateway/server/createLocalGatewayServer.test.ts`; `src/gateway/AppStateStore.test.ts`. | Local master-key storage is not a hosted KMS or universal desktop vault; managed secrets remain local to the configured app-state store. |
| Mutated headless cron prompt after grant | Denied by prompt-hash mismatch. | `src/security/agent-security-regression.test.ts`; `RunLogCron`. | Add visual console affordances so operators can inspect changed grant state without calling the API directly. |
| Deployment target/driver authority | `GatewayDeploymentControl` writes hash-only `deployment.target.write` authorization before target create/update can persist. Exact-confirmed deploy, rollback, and destroy write a matching target/plan-hash-bound `deployment.execute` decision before a driver callback receives control; hosted routes bind audit actor to the authenticated principal. | `src/gateway/GatewayDeploymentControl.test.ts`; `src/gateway/server/createLocalGatewayServer.test.ts`; `src/gateway/DeploymentWizard.test.ts`; `src/gateway/KubernetesDeploymentDriver.test.ts`. | Confirmation and decision evidence do not make local Docker, SSH, or Kubernetes execution a sandbox or production certification. |
| Client/workspace/agent topology authority | `GatewayTopologyControl` resolves opaque IDs host-side, records hash-only `topology.write` authorization before client/workspace/agent/session mutation, rejects cross-client workspace updates, and retains fail-closed linked-record deletion guards; hosted routes bind the authenticated principal. | `src/gateway/GatewayTopologyControl.test.ts`; `src/gateway/LocalGateway.test.ts`; `src/gateway/server/createLocalGatewayServer.test.ts`. | Topology authority and hosted roles do not provide tenant isolation, SSO, VM isolation, or a platform-managed vault; workspace-root and arbitrary agent metadata remain host-side state. |
| Verified marketplace installation | `GatewayMarketplaceControl` records hash-only `marketplace.catalog.sync` before pinned remote registry replacement, validates local or signed-remote template provenance and runtime profile before recording `marketplace.install`, then writes files and provisions topology under the trusted actor; failures receive a sanitized audit row. | `src/gateway/GatewayMarketplaceControl.test.ts`; `src/gateway/LocalGateway.test.ts`; `src/gateway/server/RemoteMarketplaceServer.test.ts`; `src/gateway/server/createLocalGatewayServer.test.ts`; `src/gateway/RemoteMarketplace.test.ts`; `src/gateway/TemplateMarketplace.test.ts`. | Decision evidence does not make template content safe beyond the local provenance checks, and partial file/topology work is not an automatic rollback boundary. |
| Cross-agent/channel spoofing | Accepted compatibility limitation: channel sends are not RunLog-native and are not presented as an authenticated multi-agent boundary. | `docs/implementation-backlog.md`; `docs/current-state.md`; `src/runner/ChannelBridge.ts`. | Owner: RunLog channel/identity migration. Add signed sender identity and `channel.send` decisions before promoting channels out of compatibility status. |
| Subagent privilege expansion | Local child runs inherit the parent agent, session, workspace, computer, provider/model, credential reference, and allowed tools; callers can supply only prompt, metadata, and an optional run id. A `subagent.create` DecisionRecord is appended to the parent before child creation. | `src/sdk/RunLogMainspring.test.ts`; `src/sdk/RunLogMainspring.ts`; `docs/current-state.md`. | Remote child dispatch and cross-host identity remain an accepted limitation owned by the future remote execution/identity adapter. |
| Malicious remote skill payload | Blocked or staged by the local skill provenance scanner depending on finding severity. Signed remote template catalogs cannot carry executable file types, but they are not a skill distribution path. | `src/provenance/ProvenanceReview.test.ts`; `src/gateway/RemoteMarketplace.test.ts`; `scripts/check-skill-provenance.mjs`; `scripts/check-marketplace.mjs`. | Accepted limitation, owner: remote skill trust adapter. Hosted reputation and revocation are not implemented. |
| Skill memory poisoning | Memory and skill writes are scanned and staged on review findings, with local operator review/apply surfaces and persisted taint metadata. | `src/provenance/ProvenanceReview.test.ts`; `src/gateway/LocalGateway.test.ts`; `src/gateway/server/createLocalGatewayServer.test.ts`; `MemoryTool`; `SkillTools`. | Accepted limitation, owner: context trust policy. Taint metadata is advisory; remote signing and hosted reputation remain unimplemented. |
| Browser localhost/metadata SSRF through browser adapter | Initial targets and adapter-reported current URLs after open and before/after page interaction/read actions are rejected when local/private. | `src/security/agent-security-regression.test.ts`; `src/tools/ToolRegistry.test.ts`; `BrowserTool`; `UrlPolicy`. | Accepted limitation, owner: browser lease adapter. Enforcement depends on adapters exposing `currentUrl`; trace/artifact capture policy is future work. |

## Rule

When a new tool, host surface, cron mode, memory/skill write path, subagent API, or channel adapter is added, it should land with either:

- a new row here with code-backed evidence, or
- an explicit deferred limitation in `docs/implementation-backlog.md`.
