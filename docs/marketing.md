# Marketing

## Core Message

Mainspring helps founders and operators turn raw model output into controlled agent work they can review, replay, and sell.

## Short Copy

Mainspring is the open-source operating system for agent businesses: mailbox, runtime kernel, policy guard, approvals, receipts, and run traces in one local-first package.

## Narrative

The first problem in agent products is not generation. It is consequences.

Once a model can open files, write output, run commands, or browse the web, somebody has to own the boundary between suggestion and action. Mainspring is built around that line. It keeps the model good at language and makes the runtime responsible for tools, policy, approvals, event history, and operator review.

## Use Cases

- local executive assistant for one operator
- managed customer-support agent for an agency client
- coding assistant with guarded file and shell access
- self-hosted internal ops agent with run traces and approvals
- local-first business automation without a hosted control plane

## Example Agent Businesses

- dental office intake assistant managed by a local agency
- repair shop scheduling and follow-up agent
- coding contractor toolkit for workspace summaries and guarded edits
- founder operations assistant for notes, drafts, and research

## Honest Security Posture

Marketing must keep these truths visible:

- host shell execution is not a sandbox
- browser adapter execution is trusted, not isolated
- renderer localStorage provider auth is prototype-only
- provider keys should live in env vars or secret references
- future isolation and hosted deployment work are roadmap items, not present-tense claims

## Monetization Story

Mainspring is designed for businesses that can charge for controlled agent work:

- managed retainers
- setup and integration fees
- workspace-specific operator tooling
- support and maintenance around self-hosted deployments

The current package is still pre-billing-ledger. Monetization today is operational leverage and product foundation, not built-in invoicing.
