# Brand Assets

Mainspring brand assets live here in editable SVG form.

## Files

- `mainspring-logo.svg`: full logo lockup for README headers and release notes
- `mainspring-mark.svg`: square app or avatar mark
- `mainspring-wordmark.svg`: wordmark-only lockup
- `social-card.svg`: social preview artwork
- `favicon.svg`: lightweight favicon source

## Palette

- Warm ivory: `#F3EBDC`
- Ink black: `#171513`
- Brass: `#9D7A32`
- Oxidized green: `#225C53`

## Usage Notes

- Prefer the full logo on light backgrounds.
- Use the mark where square aspect ratios matter.
- Keep the security story honest when pairing assets with marketing copy: the current package is runtime-first, local-first, and explicit about prototype console limits.
