# Support

## Where To Start

- Usage and setup: [README.md](README.md) and [docs/getting-started.md](docs/getting-started.md)
- Architecture and runtime truth: [docs/architecture.md](docs/architecture.md), [docs/current-state.md](docs/current-state.md)
- Security questions: [SECURITY.md](SECURITY.md), [docs/security.md](docs/security.md)

## Issue Routing

- Bug reports: open a GitHub issue with repro steps and expected behavior
- Security reports: use the private security path described in [SECURITY.md](SECURITY.md)
- Feature requests: describe the operator workflow, not just the UI idea

## What Maintainers Need

- Mainspring version or commit
- Node and pnpm versions
- host OS
- exact command run
- relevant logs or event output with secrets removed
